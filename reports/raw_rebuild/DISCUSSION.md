# 原始数据重建：结果与可支持的结论

**2026-10-14，原始 MIND TSV 到模型、消融、真实 HTTP 和最终验收的研究闭环已经完成。** 31 个阶段从 03:15:29 UTC 执行到 07:59:43 UTC，共 4 小时 44 分钟 14 秒；不包含此前安装与数据复制、随后最终验收。[机器生成完整结果](RESULTS.md)、[执行摘要](execution_summary.json)和[最终验收](acceptance.json)保留原始指标、区间、阶段状态及摘要绑定。

本次使用独立源代码副本、四份原始 TSV 的独立字节副本，以及不继承全局第三方包的 CPython 3.10.21 / 45 包环境。原始文件来自已有本地输入，本次没有重新下载 MIND。31 阶段覆盖 raw 到 v3 的完整依赖链，未重复不在此依赖链上的历史 v1 GBDT、ANN 或 v1 HTTP 实验。

## 哪些改进有证据

以下差值均为表中前者减后者，pp 为百分点。所有质量区间均为配对用户簇 bootstrap 的 95% 区间；神经对照 500 次，v2/v3 及外部对照 1,000 次，seed 2026。不同任务、不同数据集的数值不能直接相减。

| 对照 | 任务与样本 | 指标差值 | 95% CI（pp） | 结论 |
| --- | --- | ---: | --- | --- |
| v1 混合负例 − 随机负例 | 完整 376,471 曝光组，三 seed 逐曝光指标均值 | nDCG@10 **−0.2623 pp** | [−0.2880, −0.2350] | 此训练与选模流程退化 |
| v1 注意力 ranker − 随机负例 | 同上 | nDCG@10 **+0.0274 pp** | [−0.0247, +0.0758] | 区间跨零，不支持稳定增益 |
| v2 全特征 − 内容特征 | 12,000 曝光组、452,260 候选，三 seed | nDCG@10 **+4.4475 pp** | [+3.9561, +4.8730] | 支持曝光内排序改善 |
| v2 全特征 HGB 重排 − 不重排 | 5,000 目录请求、7,576 点击 | Recall@10 **−10.3617 pp** | [−11.3806, −9.3046] | 曝光内收益未迁移到目录任务 |
| v3 完整残差 − 热度基线 | 同一组目录请求、固定 100 候选 | Recall@10 **+0.4224 pp** | [+0.1066, +0.7618] | 本次固定 benchmark 下有正增量 |
| Adressa 旧发布完整模型 − 热度基线 | 独立出版商历史访问，15,000 请求 | HitRate@10 **−0.3733 pp** | [−0.5814, −0.1598] | 不支持冻结模型直接正向迁移 |

v1、v2 的三 seed 结果平均逐曝光指标，并非预测分数集成。用户簇区间没有重抽训练 seed；seed 间波动另外报告。v1 九组均执行两轮，但五组选中第一轮，六组难负例配置中只有一组最终保留第二轮更新。负例方案对照应解释为训练策略加内部验证选模，不能识别固定轮数下难负例的纯因果效果。[选轮与全部四项指标](V1_REBUILD.md)

v2 使用相同 50 万训练行，将 15 维内容特征扩展到 22 维内容与时序特征，平均 nDCG@10 从 0.370312 到 0.414787。内部时间窗口选定的单模型在完整 **376,471 曝光组、14,085,557 候选**上达到 **0.418905**；不能称为三 seed 全量均值。多路目录融合也没有超过热度基线：Recall@100 差值 −5.9926 pp，区间 [−6.7974, −5.1620] pp，全部 13 个目录方案均在机器报告中保留。

v3 的独立时间确认段包含 2,000 请求，Recall@10 增量 +0.3641 pp，区间 [+0.0668, +0.6396] pp，确认门通过。实际服务使用此前冻结的 `full13 + gate, δ=10`，dev 只报告结果。dev 命中从 1,779 到 1,811，主分母是全部 7,576 个日志点击；所有重排方案逐请求 Recall@100 保持一致。

## 各组件并非都有效

| v3 完整方案减去对应消融 | Recall@10 差值（pp） | 95% CI（pp） |
| --- | ---: | --- |
| 去显式类别重叠列 | −0.0132 | [−0.0399, 0.0000] |
| 去最后历史专用交互列 | 0.0000 | [0.0000, 0.0000] |
| 去历史长度门控 | −0.0660 | [−0.2499, +0.0936] |

没有稳定正向证据证明这三个组件各自提高 MIND dev 的主指标。删显式列仍可能在其他内容特征中保留同类信息；删最近历史专用交互也没有从聚合历史里移除最后一次行为。`no_gate` 点值更高，但不能根据 dev 替换预先确认的部署方案。全部消融是探索性比较，未做多重比较校正。

外部 Adressa 使用的是原发布模型，未使用本次 raw 重训模型。文本零向量、类别全部 UNKNOWN、原始行过滤及数据年代共同限制了解释，不能把负迁移归因于一个已证实原因，也不能把类别变体差值当作语义贡献。全部外部消融、审计和资源上限修订见 [外部讨论](../external/adressa_v1/DISCUSSION.md)。

## 工程闭环的证据

- 45 个锁定分发包全部重新通过校验 wheel 安装，隔离环境与 `pip check` 通过。验收绑定 103 个冻结源文件及原始数据，最终共核对 381 个文件摘要。
- 本次工作区完整测试发现 258 项，256 项通过，2 项因符号链接权限跳过；另跑 193 项研究测试全部通过，覆盖重叠。后续扩展代码的 [GitHub 独立 Windows CI](ci_checkpoint_selection.json)为 375 项全部通过，没有正式数据训练。
- 同请求 ABBA 中，1,536 个候选批次的九个字段完全一致。热派生缓存比值 **2.5456×**、冷派生缓存 **1.0699×**，是各三轮的观测耗时比，不是置信区间或端到端服务收益；历史冷态为 0.977×，不能主张稳定冷态加速。
- 新模型的真实 HTTP 完成 **768 查询、13 项接口契约**，错误、失败查询和离线不匹配均为 0。单条串行 **29.414 QPS、p95 73.876 ms**；受控服务进程采样最大 RSS **237,731,840 字节**，不含客户端和启动阶段。其余批量/并发配置全部列在机器报告，延迟是整个请求的耗时。

## 数值复现与适用范围

原始新闻 TSV、文章索引、类别、TF-IDF 词表和 IDF 一致，但重新预处理的 SVD 参数与文本向量并非逐位一致，原因尚未确定。向量几何上接近不证明下游统计等价。[数值重算](preprocessing_numeric_recomputed.json)及[来源分析](preprocessing_comparison.json)保留差异。v3 确认与 dev 的科学汇总与旧报告相同，不代表模型、数组或整条流水线字节相同。

历史从冻结处理后数据与 v2 基线起步的 v3 复训另有 9/9 模型字节一致、62 项检查通过；那是不同起点的证据，见 [交付复验报告](../DELIVERY_RESULTS.md)。本次完整重建以真实执行与验收为通过条件，没有强制匹配旧指标。

这是本地可复现的研究与服务闭环。dev 已被观察，区间条件于已实现的反馈流；CPU 性能是共享桌面观测；单机服务并不构成生产部署、线上 CTR、随机 A/B、跨日泛化或分布式集群验证。原始数据、用户记录、权重及请求日志保留在本地，仓库发布代码、复现入口与聚合证据。
