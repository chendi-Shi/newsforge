# NewsForge：大规模新闻推荐研究与 CPU 服务优化

个人研究项目｜Python / PyTorch / NumPy / scikit-learn / FastAPI｜[GitHub](https://github.com/chendi-Shi/newsforge)

以下主体条目使用 2026-10-14 原始数据重建的实测结果，另补充 2026-10-15 的目标域适配研究与最新 CI；可根据简历篇幅选取 4–5 条。

- 构建 MIND-large 推荐研究管线，使用流式扫描与 memmap 处理 **260.9 万曝光组、9759.3 万候选记录、75.0 万用户**；在 1 小时反馈成熟假设下建立 **168 个小时快照**，完成内容表示、时序特征、训练选择及数据审计。
- 实现 PyTorch 双塔、候选相关注意力与同曝光难负例训练，完成 **3 配置 × 3 seeds、各 2 个完整 epoch**，每轮使用 **286.9 万个合格正例**；按内部验证选取检查点，在完整 **37.6 万 dev 曝光组**上进行神经模型对照及用户簇配对 bootstrap。
- 对 HGB 排序开展三 seed 特征消融：相同 **50 万训练行**下，将 15 维内容特征扩展至 22 维内容与时序特征，12,000 曝光组的平均 **nDCG@10 从 0.37031 提升到 0.41479**，差值 **+4.4475 个百分点，95% CI [3.9561, 4.8730]**；内部选定单模型的完整 dev nDCG@10 为 **0.418905**。
- 针对曝光内排序改善却损害目录 Top10 覆盖的问题，设计 **13 维成对偏好模型与有界热度排名残差**，以分隔时间段完成拟合、选参和确认；固定 5,000 请求与 100 候选下，**Recall@10 从 23.4820% 提升到 23.9044%**，差值 **+0.4224 个百分点，95% CI [0.1066, 0.7618]**，逐请求 Recall@100 不变。
- 优化小时热度缓存与已读过滤，移除该路径无用双塔计算；同请求 ABBA 实验实现 **热缓存检索 2.55 倍加速**，1,536 个候选批次的九个字段完全等价。接入 FastAPI 单条/批量服务，**768 次真实 HTTP 查询零错误、零离线差异，13 项接口契约通过**；单条串行观测 **29.414 QPS、p95 73.876 ms**。
- 建立 45 包 wheel 哈希锁、独立环境安装、分阶段凭据和自动验收；在无 GPU 的本机完成 **原始数据到模型、消融与服务的 31 阶段重建**，最终验收绑定 381 个文件。扩展后的代码在独立 GitHub Windows runner 上 **418 项合成/契约测试全部通过、无跳过**。

可替换的外部验证条目：对 Adressa **308.3 万条去重访问、15,000 个固定请求**开展冻结模型迁移和全部消融，发现 HitRate@10 **下降 0.3733 个百分点，95% CI [−0.5814, −0.1598]**；完成 128 请求独立慢速审计及全部请求保存数组核验，报告词表覆盖、类别输入退化和负迁移边界。

可替换的目标域研究条目：仅使用 **4,553 篇早期标题**拟合字符 TF-IDF/SVD，将目录中文本零向量由 **24.83% 降到 0.0147%**；完成 **3 seeds × 3 变体**的共享配对训练、分时选参与确认，在主方案未优于基线时自动回退，核验 **15,000 个固定请求**及 **768 次真实 HTTP 查询、19 项接口契约**。此项体现覆盖诊断和发布决策，不写作推荐效果提升。

## 面试时需要准确说明

- 使用公开 MIND 数据，没有腾讯内部数据。最终 v3 是轻量线性成对偏好模型；神经网络研究属于 v1/v2，不将最终服务模型称为新的深度网络。所有实验均在 CPU 上完成，没有多机分布式加速证据。
- 神经消融没有证明所有设计有效：混合负例方案 nDCG@10 下降 0.2623 个百分点，注意力模型差值区间跨零。九组均训练两轮，但五组选中第一轮，因此对照包含内部验证选模，不能宣称全部最终权重保留了难负例更新。
- 曝光内排序与目录点击覆盖是不同任务。v2 的 full HGB 在目录重排中 R@10 下降 10.3617 个百分点，促使 v3 使用受约束残差。v3 消融也未证明显式类别列、最后历史专用交互列或门控分别有稳定正收益；实际服务保留确认前冻结的 `full13 + gate, δ=10`。
- dev 是已观察 benchmark；配对用户簇区间条件于固定反馈流，探索性消融未校正多重比较。离线日志点击覆盖不等于线上 CTR、因果收益或未来泛化。
- 检索倍数不包含重排和 HTTP。本次冷派生缓存比值 1.0699×、历史为 0.977×，不主张稳定冷态收益。HTTP 是共享桌面单次观测，延迟按完整请求计算，不是生产 SLO。
- 本次原始重建工作区实际 **258 项发现、256 项通过、2 项符号链接权限跳过**；另跑的 **193 项研究测试全部通过**，覆盖有重叠，不能累加。最新 418 项 CI 属于后续扩展代码的独立主机运行，不包含正式数据训练；适配轮的重复本地全仓回归因共享主机内存紧张而主动停止，没有记为通过。
- 原始重建的 SVD 参数和文本向量不是逐位一致，原因尚未确定；v3 确认与 dev 科学汇总相同不代表全系统字节一致。历史“9 个模型字节一致、62 项对照通过”从冻结处理数据和 v2 基线起步，属于另一轮局部复验。
- Adressa 使用原发布模型，并非本次 raw 重训模型；2017 年历史访问是跨出版商、跨语言压力测试。资源行数上限在部分事件已读取、效果未产生时修订；结果不支持正向迁移，也不是线上 A/B。
- 后续 Adressa 适配只在早期目标域数据上重新拟合。选参 δ=0/2/5/10 的命中数为 1,435/1,434/1,426/1,420，实际选择 δ=0、保留基线。零向量减少不等于推荐提升；δ=0 关闭全部残差，所以本轮匹配消融不能识别近期列或门控的贡献。比旧冻结模型恢复的 0.3733 pp 是回退效果，不能说成新模型收益。
