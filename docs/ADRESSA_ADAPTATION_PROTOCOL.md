# Adressa 本地字符表示与匹配重拟合协议 v1

状态：**在已知冻结迁移负结果之后提出的新适配实验；本协议不包含新模型效果。** 协议、实现、合成测试、依赖及既有输入的摘要须在首次正式拟合、调参和计算新模型效果前冻结并记录 Git commit。先前观察到的结果不能被重新包装为未见测试。本轮不修改 `newsforge/external/`、[旧协议](EXTERNAL_ADRESSA_PROTOCOL.md)、旧模型、旧抽样或[负结果](../reports/external/adressa_v1/DISCUSSION.md)。新增产物独立保存，不覆盖既有目录；失败产物也保留。

## 研究问题和范围

检验仅用较早 Adressa 标题拟合的字符 TF-IDF/SVD，以及较早下一阅读事件拟合的线性残差，能否改善同一热度候选集合的 HitRate@10。通过匹配重拟合区分“目标域权重重拟合”和“更换文本表示”两项变化。使用现有已校验 Adressa 一周事件数据库、最早标题及冻结英文特征；不重新解析原始包，不修正旧类别字段，不加入正文、翻译、会话图、协同特征或额外数据。

Adressa 只有页面访问，没有曝光列表。本实验的候选替代项是**未观察到被该请求阅读的候选**，不能称为真实曝光负例。目标是访问日志中的下一阅读排序，不是 CTR、曝光 AUC、反事实策略收益或线上 A/B 效果。候选可达率也不是召回系统的无条件全目录效果。方法采用既有字符表示和 pairwise logistic 技术；贡献边界沿用 [RELATED_WORK.md](RELATED_WORK.md)，不宣称新语言模型或新算法。

## 1. 日期与可用信息

所有时间采用原始 Unix 秒的 UTC 坐标，区间为左闭右开：

| 阶段 | 区间或截点 | 固定用途与上限 |
|---|---|---|
| representation | `article.first_seen < 2017-01-01 23:00:00` | 每篇满足条件的文章一次，用首次标题拟合字符表示 |
| fit | `[2017-01-02 00:00:00, 2017-01-02 23:00:00)` | 最多 30,000 个请求；拟合残差与标准化 |
| tune | `[2017-01-03 00:00:00, 2017-01-03 23:00:00)` | 最多 5,000 个请求；仅选择本地 full13 的 delta |
| confirm | `[2017-01-04 00:00:00, 2017-01-04 23:00:00)` | 最多 5,000 个请求；一次性决定适配回放策略是否启用残差 |
| observed benchmark | Jan 5、6、7 的原 v1 完整评估日 | 原样复用已保存的每天 5,000、合计 15,000 个请求 |

表示、拟合、调参和确认的可用信息分别在下一阶段 00:00 前留出至少一小时成熟间隔。23:00 等号排除；表示拟合不包含 Jan 1 23:00 及以后的文章。间隔内事件仍可按原时序规则更新历史和公共热度，但不能加入上一阶段的模型拟合或选择样本。后续阶段不重新拟合表示、标准化或系数，也不合并 fit 与 tune 再训练。

Jan 1–4 先前已被读取并用于旧实验暖机，Jan 5–7 的旧模型结果已经观察。本轮的 Jan 4 只称为**按本轮规则保留的确认端点**，不称为从未接触过的数据；Jan 5–7 始终称为**已观察基准上的回顾性评估**，不是新的独立外部测试。按时间先后保留端点可以限制本轮选择，但不能消除研究方向受到旧结果影响的事实。

## 2. 固定样本、候选及因果状态

fit、tune、confirm 均先从相应区间的全部合法去重事件中，按以下 SHA256 字节值升序取上限内的请求：

```text
SHA256(UTF8("newsforge-adressa-adapt-v1|" + phase + "|" + member_name + "|" + decimal_line_number))
```

`phase` 只取 `fit`、`tune`、`confirm`；物理身份是旧数据库中的原始成员名和一基行号。hash 并列按 `(member_name UTF-8 字节序, line_number)` 排序。抽样不读取目标文章、历史长度、覆盖率或模型得分；不足上限则使用全部并报告。正式效果计算前保存样本身份摘要、总体数和实际数。Jan 5–7 必须复用旧 `sampled` 表及其样本摘要，不使用新 hash 重抽，也不为了补足命中而加入目标。

全部方法逐请求共用旧 v1 的候选和历史定义：

- 请求 `t` 的用户历史仅含 `event_time < t`；同秒事件互相不可见。内容特征取最后 20 条，候选过滤使用全部过去已读文章。
- `T=floor(t/3600)*3600`，公共截止 `C=T-3600`。热度和可见文章只使用严格早于 `C` 的信息；半衰期 12 小时的小时 EMA、24 小时首次观察窗、近期 200 / 最终 100 预算、全目录补位和稳定并列规则全部沿用旧实现。
- 每个合法去重事件只更新公共状态一次；未抽中的事件仍按时序进入历史和热度。方法数、seed 数及重复评分不得改变公共状态。
- 文章只用第一次合法事件的标题版本；不得利用后续标题修订补全空值。预先 transform 未来文章只能作为缓存，不能让它参与较早请求的候选或历史。
- 全部评估请求保留在主分母，包括空历史、目标尚不可见、目标已读、目标不在候选和候选不足的请求；不按训练资格筛选评估集。

## 3. 本地字符表示

表示语料只含第 1 节截点之前首次出现的文章，每篇一条固定首次标题，按原文章 ID 字节序排列；空标题不补全。不得用全周标题拟合词表、IDF、SVD、秩数或覆盖阈值。配置固定为：

```text
TfidfVectorizer(analyzer="char_wb", ngram_range=(3, 5), min_df=2,
                max_features=40000, sublinear_tf=True, norm="l2", dtype=np.float32)
TruncatedSVD(n_components=96, random_state=2026, n_iter=7)
```

其余参数使用冻结 scikit-learn 版本的默认值，并在 receipt 记录完整参数和实际版本；不按效果改动。SVD 输出逐行 L2 normalize 后存为 float32；padding 行全零。随后仅调用固定变换器的 `transform` 处理其他首次标题。若语料或词表不足以产生规定的 96 维，或出现非有限值，则失败并报告，不能静默选择其他维数。

字符边界分析、词组长度范围、sublinear TF 和 L2 参数语义见 [scikit-learn 1.6 TfidfVectorizer 官方文档](https://scikit-learn.org/1.6/modules/generated/sklearn.feature_extraction.text.TfidfVectorizer.html)。字符表示可能改善语言内词形覆盖，这是待检验动机，不等于跨语言语义能力证明。

仅替换原输入的前 96 个文本维；类别后缀原样保留。旧适配器全部类别为 UNKNOWN，因此不把本轮差异归因为类别语义。英文对照直接复用旧冻结英文表示。两种表示均调用原 `content_features` 的前 13 列；不将新 SVD 填入旧 MIND 残差后直接冒充匹配模型。

分别报告表示拟合文章数、词表大小、SVD 维数，以及全目录、各阶段候选/历史的空标题、零 TF-IDF、零 SVD 和 UNKNOWN 类别比例。覆盖诊断不用于剔除请求或再次选择编码器。

## 4. 共享训练配对与模型

只有已抽中的 fit 请求在**目标确实位于原候选池、历史非空、至少存在一个其他候选**时形成训练配对。报告抽样总数、合格数及各项不合格原因；这只是可拟合样本定义，不改变评估总体。

对每个 seed `17/29/43`，以 `np.random.default_rng(seed)` 初始化一次，按 `(timestamp, member_name UTF-8 字节序, line_number)` 遍历 fit 请求；在原候选顺序中排除目标后，均匀无放回抽取 `min(8, 其余候选数)` 个替代项。每个 seed 的请求和替代文章身份在所有重拟合模型间完全相同，配对摘要必须一致。不同 seed 的区别来自配对抽样，不把优化器描述为随机神经训练。

使用现有 `PairwiseResidual`：相等配对权重、配对两侧 fit 特征的总体 mean/SD、零方差 scale=1、无截距 pairwise logistic 损失、L2=0.01、L-BFGS-B 最多 200 轮。标准化及系数仅来自 fit 配对；优化不收敛时保留失败，不根据 tune/confirm 结果重试新参数。每个重拟合变体独立拟合其对应特征列。

固定比较包含：

| 方法 | 表示 / 权重 | delta |
|---|---|---|
| baseline | 原热度顺序 | 0 |
| frozen_english_matched | 原英文表示 / 原 MIND full13 三 seed | 共同选中的 delta |
| refit_english | 原英文表示 / Adressa fit 的 full13 三 seed | 共同选中的 delta |
| refit_local（唯一主方案） | 本地字符表示 / Adressa fit 的 full13 三 seed | 共同选中的 delta |
| refit_local_no_recent | 本地字符表示 / Adressa fit 的 no_recent 三 seed | 共同选中的 delta |
| refit_local_no_gate | 与 refit_local 相同表示和权重，取消非空历史的门控 | 共同选中的 delta |
| frozen_english_legacy | 原英文表示 / 原 MIND full13 三 seed | 原 v1 的 10 |
| selected_policy | 确认通过时为 refit_local，否则为 baseline | 由第 5 节决定 |

`no_recent` 仅移除第 13 列最近一次有效历史的专用相似度；它仍可通过其他历史统计使用最近事件，不称为移除全部近期信息。重拟合英文与冻结英文对比检查目标域权重变化；重拟合本地与重拟合英文检查固定强度下表示变化；no_recent 检查专用列的描述性差异。

各 seed 的 raw score 先 clip 到 `[-1,1]`，再平均；`n=min(历史条数,20)`，共同门控 `g=n/(n+5)`，排序分数为 `-original_rank + delta*g*mean_clipped_score`。空历史严格返回 baseline；相同分数保留原热度顺序。所有模型采用同一 delta 是固定强度的匹配比较，不代表每个消融都独立调参后的最优表现。legacy 对照另列，不能把不同 delta 的差异全归因于模型。

`refit_local_no_gate` 是预先固定的描述性推理消融：仅对非空历史把 `g` 换成 1，仍沿用 full13 三 seed 权重和所选 delta，不增加拟合或调参；空历史仍严格返回 baseline。它不参与主方案选择或确认门。

## 5. 唯一选择与确认门

仅在 tune 上比较 **refit_local full13** 的 `delta ∈ {0,2,5,10}`，按全样本 HitRate@10 最高者选择，并列取较小 delta。不比较 seed 子集，不用 MRR、子人群、单日或消融结果打破并列；其他方法无独立调参。选定 delta 和模型摘要写入不可覆盖的 selection 记录，再执行 confirm。

confirm 只检验一个主比较：选定 refit_local 减 baseline 的配对 HitRate@10 差。只有 **delta>0、差值点估计>0、双侧 95% 用户簇 bootstrap 区间下界>0** 同时成立，才令本实验 `selected_policy=refit_local`；否则选 baseline。没有另外的业务最小收益阈值；不通过也必须报告原始模型结果。

确认仅执行一次；失败后不改模型、种子、窗口、delta、门控、分母或判据，也不从其他变体中补选获胜者。Jan 5–7 同时报告原始主方案和 selected_policy，不凭已观察基准结果反转确认决策。这里的 selected_policy 只表示本适配实验的回放策略，**不替换 MIND 服务、已有发布模型或旧外部实验**。

## 6. 指标、区间与结论边界

主指标为 `HitRate@10=前10含目标的请求数/全部固定请求数`；每请求一个目标，本任务中等于 micro Recall@10。报告整数命中与总分母、HitRate@10、HitRate@100、MRR@10（未命中为 0），以及 Jan 5–7 整体和逐日结果。全部方法候选集合和 HitRate@100 必须完全相同。

对每次配对比较，先跨相关日期合并每用户的请求数与命中差，再以 `np.random.default_rng(2026)` 有放回抽取与原来数量相同的用户簇，重复 1,000 次；每次计算抽中簇的总命中差/总请求数，取 percentile 双侧 95% 区间。每个日期或独立比较重新初始化 seed 2026；用户顺序固定为原稳定用户 ID 升序。同用户跨日请求保持同簇。确认门只使用 confirm 的用户簇区间。

除唯一确认比较外，英文重拟合、表示变化、no_recent、legacy、逐日和覆盖分组比较均为描述性分析；不将多个未校正区间用于另选主结论。区间条件于已实现的日期和共享新闻/反馈流；用户聚类不消除共同文章冲击，也不代表未来日期、其他出版商或线上收益的不确定性。

Jan 5–7 的总体沿用每日等额 5,000 抽样，不称为全三日流量加权效果。分别报告配对获益/受损请求数、空历史、目标不可见/已读/不在池、候选 shortfall、补位及覆盖；可重叠诊断不相加成互斥人群。即使新方案优于 baseline，也不能撤回旧冻结迁移负结果或称为未经观察的新外部成功。

## 7. 预算、验证与证据链

CPU 单进程、数值线程 1；每请求候选最多 100、特征历史最多 20；字符词表最多 40,000、文本维数 96、transform 批次最多 4,096；fit 最多 30,000 请求、每请求每 seed 最多 8 配对、三个 seed、三个新拟合变体；调参仅四个 delta；bootstrap 1,000 次。不启用神经训练、GPU、会话图或新的大规模数据处理。记录各阶段实际耗时、采样 RSS、输入规模和实际配对数，不把运行估计写为实测性能，也不将含准备/审计的时间当纯推理吞吐。

正式运行前合成验证至少包括：表示截点等号排除；未来标题/事件扰动不影响较早拟合或排名；同秒历史隔离；公共截止等号排除；抽样不依赖目标；共享配对身份；训练标准化不读取 tune/confirm；空历史及 delta=0 回退；稳定并列；候选集合恒等；确认失败回退。使用独立慢速计算核验至少 128 个按固定样本身份顺序均匀选取、含首尾的 benchmark 请求，候选、排名及命中要求相同，分数 `atol=1e-8, rtol=0`。参考路径共享特征定义的部分须明确披露。

记录旧准备数据库、首次标题表/输入、英文特征、原权重、协议、实现、依赖锁、阶段样本、共享配对、本地变换器、新权重、selection、逐方法预测和聚合结果的 SHA256/大小或规范化摘要链。阶段间校验冻结绑定，正式运行结束再次校验旧实验与 MIND 输入未变。公开 Git 只含代码、协议和不泄露个人记录的汇总；原始日志、标题、匿名用户身份、逐请求数组、词表及模型产物保留本地。
